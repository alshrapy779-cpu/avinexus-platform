Test method
-----------
A clean copy of the full V20.2.6 baseline was created in a temporary test directory. The V20.2.7 patch manifest and payload were then applied using the same baseline-hash, copy and post-copy-hash semantics implemented by the PowerShell upgrade script. The test then removed all V20.2.7 new files, restored all modified V20.2.6 files from backup, and compared every restored baseline file SHA-256 with the original V20.2.6 baseline.
