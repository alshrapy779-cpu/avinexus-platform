AviNexus Poultry Enterprise - Windows Test Package (NOT PRODUCTION CERTIFIED)

START HERE - تشغيل المنصة في ويندوز

1. فك ضغط كامل الأرشيف. افتح المجلد project.
2. ثبّت Node.js إصدار 22 أو 24 LTS من الرابط الرسمي https://nodejs.org/en/download
   (لا يكفي تنزيل ملف التثبيت فقط؛ يجب تثبيته وإغلاق نوافذ الأوامر القديمة.)
3. انقر مرتين على INSTALL_AND_START_WINDOWS.bat الموجود داخل project.
4. انتظر تثبيت الحزم، اختبارات المصدر، والبناء. عند النجاح سيفتح http://localhost:3000
5. لإعادة التشغيل في وقت لاحق استخدم windows/START_WINDOWS_PLATFORM.bat
6. لإيقاف الخادم استخدم windows/STOP_WINDOWS_PLATFORM.bat
7. إذا فشل التشغيل، صوّر كامل رسالة الخطأ أو ارسل الملف logs/windows-platform.err.log إن وجد.

تنبيهات:
- لا تستخدم BUILD_APK_COMPLETE.bat؛ فهذا لإنشاء تطبيق Android، ويتطلب Java/Android SDK.
- لا تضع بيانات التشغيل القديمة أو قاعدة البيانات داخل مجلد يتم استبداله دون نسخة احتياطية.
- يحتفظ البرنامج بملفات runtime-data وسجلات logs في مجلد المشروع. لا تحذفها بعد بدء الاستخدام.
- لا تدخل مفتاح Gemini أو أسرار النظام في المحادثة؛ استخدم .env على جهازك عند الحاجة.
- تم إصلاح استيراد dotenv وفحص رموز الخروج من npm وتحديث فحص بصمات المصدر
  ليستوعب الملفات المستعادة في لقطة 2026-10-20 (ببصمات ثابتة)، دون حذف أقسام.
- هذا تعديل لسهولة التثبيت والاختبار وليس شهادة نجاح للبناء الفعلي على جهاز Windows.
- لا يعتبر النظام جاهزاً للإنتاج قبل التحقق من الوظائف، الصلاحيات، البيانات، الطباعة،
  وثبات السجلات عبر إعادة تشغيل ويندوز.
